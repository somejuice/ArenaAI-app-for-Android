# ArenaAI for Android

> 非官方、独立维护的 ArenaAI 第三方 Android 客户端。

![Version](https://img.shields.io/badge/version-1.6.0--release-315BD2)
![Android](https://img.shields.io/badge/Android-7.0%2B-3DDC84)
![Languages](https://img.shields.io/badge/languages-中文%20%7C%20English%20%7C%20日本語-6E7781)

ArenaAI 将相关网页服务封装为便于移动设备使用的 Android 客户端，并提供语言切换、主题设置、网页辅助功能以及独立的隐私政策入口。

> [!IMPORTANT]
> 本项目是非官方第三方客户端，与 Arena.ai、其运营方、模型提供方或其他相关第三方不存在隶属、代理、赞助、背书或合作关系。相关名称、商标、内容和服务的权利归各自权利人所有。

## 功能

- 移动端网页访问界面
- 中文、英文和日文界面
- 浅色、深色及跟随系统主题
- 网页刷新、外部浏览器打开及文件选择
- 可选的网页翻译辅助功能
- 独立的“隐私政策”侧边栏入口
- 首次启动政策确认：
  - 必须阅读并明确同意后才能继续
  - 不同意或返回时退出应用
  - 按政策版本记录同意状态与时间
  - 政策更新后可重新要求用户确认

## 下载与安装

1. 前往仓库的 [Releases](../../releases) 页面。
2. 下载 `ArenaAI-1.6.0-release-modified.apk`。
3. 在 Android 系统中允许所用浏览器或文件管理器“安装未知应用”。
4. 打开 APK 并按照系统提示完成安装。
5. 首次启动时阅读隐私政策，勾选确认后点击“同意并继续”。

### 无法覆盖安装

此构建使用独立的发布证书签名。如果设备中已安装使用其他证书签名的同包名应用，Android 会拒绝覆盖安装。

请先备份必要数据，再卸载旧版本后安装。**卸载应用通常会清除其本地设置、Cookie、登录状态及其他应用数据。**

```text

```

发布证书 SHA-256 指纹：

```text
13cd99021b12a075cec3be33f1dc0187c44d006d3772b2ef682c52d3727c40cb
```

Linux、macOS：

```bash
shasum -a 256 ArenaAI-1.6.0-release-modified.apk
```

Windows PowerShell：

```powershell
Get-FileHash .\ArenaAI-1.6.0-release-modified.apk -Algorithm SHA256
```

请确认计算结果与上方 APK 校验值一致。
