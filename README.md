# ArenaAI for Android

> 非官方、独立维护的 ArenaAI 第三方 Android 客户端（社区修改版）。

![Version](https://img.shields.io/badge/version-1.7.1--b29-315BD2)
![Android](https://img.shields.io/badge/Android-7.0%2B-3DDC84)
![Languages](https://img.shields.io/badge/languages-中文%20%7C%20English-6E7781)

ArenaAI 将相关网页服务封装为便于移动设备使用的 Android 客户端，在原生 Material 3 界面中提供模型选择、对话、排行榜与历史记录，并支持语言切换、主题设置、网页辅助功能以及独立的隐私政策入口。

## 功能

### 原生体验
- 原生 Material 3 界面：对话气泡、模型选择表单、排行榜、历史抽屉与设置
- 多模式切换：直连 / 智能体 / 对比 / 对战 / 排行榜
- 模型选择按**厂商自动分组**（OpenAI、Google、Anthropic、DeepSeek 等）
- 原生渲染与网页渲染一键切换（网页回退）

### 模型选择（本次重点更新）
- **自定义模型持久化**：在「选择模型 → 自定义模型」中输入的模型会被保存，下次打开仍可见
- **按所属类别自动归类**：自定义模型按名称前缀自动推断厂商并归入对应分组（如 `gpt-*` → OpenAI、`claude-*` → Anthropic、`gemini-*` → Google），无法识别的归入「Custom」分组
- 自定义模型**置顶显示**，不会被长列表截断
- 模型清单渲染上限提升，可浏览更多模型（旧版本仅显示前 60 个）

### 智能体模式（本次修复）
- 修复智能体（Agent）模式**无法发送消息**的问题：针对其 TipTap/ProseMirror 富文本输入框重写了文本注入与发送流程

### 通用
- 中文、英文界面
- 浅色、深色及跟随系统主题；动态取色（Android 12+）
- 网页刷新、外部浏览器打开及文件选择
- 拦截广告与追踪、触感反馈、回车发送等行为开关
- 可选的网页翻译辅助功能
- 独立的「隐私政策」侧边栏入口
- 首次启动政策确认：
  - 必须阅读并明确同意后才能继续
  - 不同意或返回时退出应用
  - 按政策版本记录同意状态与时间
  - 政策更新后可重新要求用户确认

## 下载与安装

1. 前往仓库的 [Releases](../../releases) 页面。
2. 下载 `ArenaAI-1.7.1-b29.apk`。
3. 在 Android 系统中允许所用浏览器或文件管理器「安装未知应用」。
4. 打开 APK 并按照系统提示完成安装。
5. 首次启动时阅读隐私政策，勾选确认后点击「同意并继续」。

### 无法覆盖安装（重要）

本构建使用独立的**调试证书**重新签名，其签名与任何官方签名的 ArenaAI 均不同。如果设备中已安装官方版或其他证书签名的同包名应用，Android 会拒绝覆盖安装。

请先备份必要数据，再**卸载旧版本后安装**。**卸载应用通常会清除其本地设置、Cookie、登录状态、自定义模型记录及其他应用数据。**
